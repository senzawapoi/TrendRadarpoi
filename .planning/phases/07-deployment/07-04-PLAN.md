# 07-04 Plan: Runbook, Restore, and VPS Acceptance

## Goal

Close the deployment loop with operator documentation and evidence-driven
restore and continuous-runtime acceptance.

## Deliverables

- First-install, upgrade, pause, rollback, and shutdown runbook.
- Isolated restore command with persistent restore guard and no automatic
  replay of uncertain external deliveries.
- Backup retention and remote-copy procedure with manifest verification.
- D0-D4 staged enablement matrix, health evidence, and Phase 5 C3/C4
  relationship clearly recorded.
- VPS preflight and acceptance forms. Missing live host evidence remains an
  explicit open item.
