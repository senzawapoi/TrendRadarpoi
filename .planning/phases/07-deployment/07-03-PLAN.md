# 07-03 Plan: Reproducible Build, CI, Backup, and Release

## Goal

Produce a deterministic, secret-free release artifact and a reversible,
serialized deployment path.

## Deliverables

- Release manifest with commit/diff state, package versions, Python/SQLite
  evidence, schema range, tests, artifact digest, and rollback reference.
- Reproducible build/check script without runtime databases or credentials.
- CI checks for dependencies, tests, Ruff, imports, package resources, unit
  syntax, schema behavior, and secret/artifact boundaries.
- Versioned systemd/deployment templates and an explicit release lock.
- SQLite Online Backup based snapshot/manifest tooling; no copying live `.db`
  files as a fake consistent backup.
