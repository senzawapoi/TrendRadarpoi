# 07-02 Plan: Configuration, Health, and Resource Boundaries

## Goal

Give every role stable paths, sanitized status, explicit environment
contracts, bounded resources, and diagnosable logs.

## Deliverables

- Stable `/opt`, `/etc`, `/var/lib`, `/run`, and backup layout templates.
- Role-aware configuration summary and an offline `ops health` command.
- Persistent health/progress fields for Bot, Worker, Scheduler, collectors,
  queue, delivery, and database/schema.
- systemd hardening/resource templates that are documented as candidates until
  measured on the target VPS.
- Secrets only through environment files; no secrets in YAML, manifests,
  health output, logs, or artifacts.
- Validation for missing databases, wrong paths, schema mismatch, stalled
  workers, stale queues, and write failures.
