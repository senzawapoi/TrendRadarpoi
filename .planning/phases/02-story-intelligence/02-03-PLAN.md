<objective>
Generate readable Stories deterministically from clusters and define an optional wording-only
Gemini boundary that can never control Story identity, membership, ranking, or availability.
</objective>

<tasks>

<task type="implementation">
  <name>Build deterministic Story generator</name>
  <files>trendradar/intelligence/story_generator.py</files>
  <action>
    Implement generate_story(cluster, items, wording_client=None) using stable member ordering.
    Select a deterministic representative title, strip repeated source prefixes, and build a
    bounded summary from the first non-empty content plus source/member context. Populate stable
    Story ID/signature, tags, event time, member IDs, and generator version. Handle missing content,
    missing publish times, and singleton clusters without exceptions. Do not import mcp_server or
    instantiate a provider here.
  </action>
  <done>Deterministic generation handles singleton, multi-member, empty-content, and missing-time cases with bounded fallback title and summary.</done>
  <verify>python -m pytest tests/intelligence/test_story_generator.py -q</verify>
  <acceptance_criteria>Identical cluster input always yields byte-equivalent fallback fields and a
    usable Story offline, including when all content is empty.</acceptance_criteria>
</task>

<task type="implementation">
  <name>Add optional wording-only enhancement</name>
  <files>trendradar/intelligence/story_generator.py, trendradar/intelligence/stories.py</files>
  <action>
    Accept an injected callable/protocol that receives deterministic title/summary context and may
    return replacement wording. Validate non-empty bounded strings, catch timeout/provider/parser
    errors, log them, and retain fallback wording. Never pass or accept IDs, member lists, score,
    evidence, or ranking decisions from the client. Keep the service usable when no Gemini key or
    dependency exists.
  </action>
  <done>The optional client is lazy, validates only wording fields, and preserves fallback output on every provider or parser failure.</done>
  <verify>python -m pytest tests/intelligence/test_story_generator.py -q</verify>
  <acceptance_criteria>Successful enhancement changes wording only; every client failure produces
    the same deterministic fallback and does not fail acquisition or persistence.</acceptance_criteria>
</task>
