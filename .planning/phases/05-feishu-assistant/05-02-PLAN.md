<objective>
Receive Feishu message events through the official WebSocket SDK, normalize private and group
messages, and route authorized text/image input to the existing Assistant service.

Purpose: deliver the first end-to-end conversational path while keeping authorization before
Assistant/Gemini invocation and keeping the transport independent from provider SDK types.
</objective>
