# Plan 02: SourceAdapter and Runner

## Objective

Provide failure-isolated asynchronous adapters and passive source health reporting.

## Tasks

1. Define generic `SourceAdapter`, `SourceHealth`, `HealthStatus`, and `AdapterResult` contracts.
2. Implement a bounded runner that isolates fetch and item normalization failures and records
   source runs without allowing telemetry writes to fail acquisition.
3. Implement NewsNow, RSS, and AI Frontier wrappers. Preserve NewsNow ordering and delay,
   default RSS concurrency 5, and existing `AISource` parser ownership.
4. Test concurrency ceilings, serial execution, passive health, empty/partial/terminal states,
   and source wrapper behavior.
