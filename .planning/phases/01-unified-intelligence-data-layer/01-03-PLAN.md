# Plan 03: Migrate Existing Sources

## Objective

Make adapters the default acquisition path while preserving all legacy public APIs and outputs.

## Tasks

1. Route NewsNow platforms and RSS feeds through adapters and project raw normalized records back
   into existing `NewsData`, `RSSData`, grouping, ordering, names, and failed IDs.
2. Route enabled AI Frontier top-level source blocks through adapters while retaining
   `build_sources()`, `fetch_all()`, and `fetch_and_process()` compatibility.
3. Keep reports, notifications, translation, MCP, and all legacy SQLite writes on their existing
   models and schemas.
4. Test default adapter selection, explicit legacy rollback, projection fidelity, source failure
   isolation, and offline entrypoint imports.
