# Plan 01: ContentItem, Normalize, and Unified Storage

## Objective

Establish the canonical content contract, lossless legacy conversions, and versioned local
SQLite storage without changing any legacy schema.

## Tasks

1. Add `ContentItem`, UTC validation, JSON serialization, deterministic UUIDv5 identity,
   Unicode/whitespace/tag/time/URL normalization, and domain/source validation.
2. Add lossless `NewsItem`, `RSSItem`, and `AIItem` compatibility conversions.
3. Add `IntelligenceStorage` with WAL, foreign keys, five-second busy timeout, schema version 1,
   and the `content_items`, `content_observations`, and `source_runs` tables.
4. Test validation, normalization, serialization, conversion round trips, transactions,
   provenance, concurrent connections, and idempotent upserts.
